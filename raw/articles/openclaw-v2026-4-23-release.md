# OpenClaw v2026.4.23 Release Notes

**Source:** Based on Jdon.com + CSDN reports (2026-04-25)

## Core Update: GPT-5.5 Integration

OpenClaw v2026.4.23 正式接入 **GPT-5.5**，是本版本最核心的升级。

## Key Changes

### 1. GPT-5.5 as Primary Model
- 大脑换成 GPT-5.5，相当于给机器人换了一块更聪明的芯片
- 推理能力、多模态理解进一步提升

### 2. Dual Image Generation Channels
- 新增两条图像生成通道
- 一条使用 Codex API
- 支持更高质量的图像生成

### 3. Subagent Branch Context Mechanism
- 引入**子智能体分支上下文机制**
- 子智能体可以"继承记忆"
- 任务分支现在可以保留上下文

### 4. Local Embedding Model Optimization
- 优化本地嵌入模型
- 工具超时控制改善

### 5. Previous Updates in v2026.4.x Line
- v2026.4.20: Moonshot Kimi K2.6 支持，分层模型定价
- v2026.4.22: 腾讯混元上线，多模态闭环

## Version Context
This is part of the rapid v2026.4.x iteration cycle following v2026.4.14 (security hardening).
