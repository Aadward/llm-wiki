# OpenClaw 2026.3.31 版本更新：安全加固、后台任务管理增强

## 核心新功能：后台任务管理 + 任务流控制

### 后台任务管理
- 将任务转变为真正的**共享后台运行**控制平面
- 统一 ACP、子代理、cron 和后台 CLI 执行
- **SQLite 支持的分类账**，路由分离的生命周期更新
- 添加审计/维护/状态可见性改进
- 任务感知和丢失运行恢复

### 任务流控制（Flows CLI）
首个线性任务流控制界面：
```bash
openclaw flows list    # 列出所有流
openclaw flows show    # 查看流详情
openclaw flows cancel  # 取消流
```
- 保持手动多任务流与单任务自动同步流分离
- 为孤立或损坏的流/任务链接提供 `doctor` 修复

## 安全加固（2026.3.31）

### 网关认证加固
- `trusted-proxy` 现在拒绝混合共享令牌配置
- 本地直连回退需要使用配置的令牌，不再隐式认证
- 同主机调用设备令牌轮换后立即断开活动会话

### 节点命令安全
- 节点命令现在保持禁用状态直到节点配对被批准
- 设备配对本身不再足以暴露声明的节点命令

### 执行安全
- 阻止请求范围的环境变量覆盖（Docker 端点、TLS 证书、包索引等）
- 阻止 Python 包索引覆盖变量从请求范围的执行环境中泄露

### 技能安装安全
- 内置危险代码 critical 发现和安装时扫描失败现在默认失败
- 关闭插件安装和网关支持的技能依赖安装
- 可能需要显式危险覆盖才能继续
